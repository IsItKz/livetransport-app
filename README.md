# Live Transport App
Мобилно приложение за следене на градския транспорт в реално време в София и други градове.

Вдъхновено и базирано на уеб картата [livetransport.eu](https://livetransport.eu), създадена от **Милен-Йоан** ([@BPilot253](https://github.com/BPilot253)).

## Основни функции
- Локално запазване на любими линии, спирки и настройки (независими от браузърния кеш)
- По-удобно и лесно мобилно изживяване
