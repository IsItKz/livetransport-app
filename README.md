# 🚌 Live Transport App

[English](#english) | [Български](#български)

---

## English

A native mobile wrapper for the [livetransport.eu](https://livetransport.eu) web map, bringing real-time public transit tracking to a dedicated mobile app experience.

> **Note:** This project is a native container/wrapper for the web service created and maintained by **Milen-Joan** ([@BPilot253](https://github.com/BPilot253)). 

### ✨ Features & Mobile Enhancements
* **Dedicated Mobile Container:** Quick access without using a web browser tab.
* **Persistent Settings:** Keeps local storage for favorite routes, stops, and settings intact.
* **Fullscreen Experience:** Optimized mobile UI without browser address bars.
* **Native Android Integration:** Custom native bridge layer for smooth rendering and lifecycle handling.

### 🛠️ Built With
* **Framework:** [React Native](https://reactnative.dev/)
* **Native Android Code:** Kotlin & Java

### 🚀 Download & Installation
* Download the compiled `.apk` / build from the [Releases](../../releases) tab.
* *Requires an active internet connection to fetch real-time transit data.*

## Български

Мобилно приложение (wrapper) за уеб картата [livetransport.eu](https://livetransport.eu) за следене на градския транспорт в реално време.

> **Забележка:** Този проект е мобилен контейнер за уеб услугата, създадена от **Милен-Йоан** ([@BPilot253](https://github.com/BPilot253)).

### ✨ Предимства
* **Самостоятелно приложение:** Бърз достъп без нужда от отваряне на браузър.
* **Запазване на настройки:** Локално съхранение на любими спирки и линии.
* **Мобилен изглед:** Премахва лентата с адреса за по-удобен преглед на картата.
* **Нативна Android интеграция:** Персонализиран нативен мостов слой за плавно рендериране и управление на жизнения цикъл.

### 🛠️ Използвани технологии
* **Фреймуърк:** [React Native](https://reactnative.dev/)
* **Нативен Android код:** Kotlin & Java

### 🚀 Изтегляне и инсталация
* Изтеглете компилирания `.apk` / версия от раздела [Releases](../../releases).
* *Изисква активна интернет връзка за извличане на данните в реално време.*
